FORMULAS
  Linear model     y_hat = theta0 + theta1*x1 + ... + thetan*xn = X_b @ theta   (X_b = [1, X])
  MSE              mean((y_hat - y)^2)
  Normal equation  theta = (X^T X)^-1 X^T y
  Ridge            theta = (X^T X + lam*I)^-1 X^T y      (I[0,0] = 0, don't penalise the bias)
  GD gradient      grad = (2/n) X^T (X theta - y)    ;   theta -= lr * grad
  R2               1 - sum((y - y_hat)^2) / sum((y - mean(y))^2)
  RMSE             sqrt(mean((y - y_hat)^2))
  Standardise      z = (x - mean_train) / std_train
  Sigmoid          1 / (1 + e^-z)
  Accuracy         (TP+TN) / all
  Precision        TP / (TP+FP)       "of my YES calls, how many right"
  Recall           TP / (TP+FN)       "of real YES, how many caught"
  F1               2PR / (P+R)        macro F1 = average F1 over classes (multi-class)

DATA PREP
  df.isnull().sum()            missing values -> df.dropna()  or  df.fillna(df.mean(numeric_only=True))
  pd.get_dummies(df, drop_first=True).astype(float)      text -> 0/1 columns
  drop: id columns, raw date strings, and any column that IS the answer (leakage)
  dates: pd.to_datetime(df.date, dayfirst=True).dt.hour / .dt.dayofweek / .dt.month

COMMON ERRORS
  could not convert string to float   -> forgot get_dummies / drop a text column
  LinAlgError: Singular matrix        -> use np.linalg.pinv or add lam (Ridge) > 0
  GD loss = nan / inf                 -> lower lr (/10) and STANDARDISE X
  shapes not aligned                  -> X needs 2-D: X[:, [j]] not X[:, j]; given row via make_row()
  R2 scratch != sklearn               -> bias column missing or scaled with test stats
  f1_score "Target is multiclass"     -> add average="macro"
  ConvergenceWarning (LogReg)         -> max_iter=2000 and scale X
